## Execution Order (13 steps)

### Step 1: glTF 2.0 Importer
- Files: `engine/assets/include/nexus/assets/gltf_importer.h`, `engine/assets/src/gltf_importer.cpp`
- Full glTF 2.0 JSON+GLB parser: meshes (multi-primitive), materials (PBR metallic-roughness), skeletons (joints+weights), animations (translation/rotation/scale channels)
- Accessor/buffer-view/buffer resolution pipeline
- Integrate with existing asset_loader.cpp registry
- Add to `engine/assets/CMakeLists.txt`

### Step 2: Shader Cache
- Files: `engine/renderer/src/shader_library.cpp` (extend existing)
- Binary program caching: `glGetProgramBinary` / `glProgramBinary` for GL
- Cache directory: `.nexus/shader_cache/` with hash-based filenames
- Invalidation: hash of source + defines + GL version
- Add `save_cache()` / `load_cache()` to ShaderLibrary

### Step 3: PCSS (Contact-Hardening Soft Shadows)
- Files: `engine/renderer/src/shadow_map.cpp` (extend SHADOW_SAMPLING_GLSL)
- Blocker search pass (average blocker depth in penumbra region)
- Variable PCF kernel size based on blocker distance
- Add `sampleShadowPCSS()` to the exported GLSL string

### Step 4: Lightmap Baker
- Files: `engine/renderer/include/nexus/renderer/lightmap_baker.h`, `engine/renderer/src/lightmap_baker.cpp`
- UV2 atlas layout (simple grid packing)
- Progressive rendering: accumulate direct + indirect lighting per texel
- Hemisphere sampling with cosine-weighted directions
- Output: lightmap texture + UV2 mapping per mesh
- Add to renderer CMakeLists.txt

### Step 5: Reverb Zones
- Files: `engine/audio/include/nexus/audio/reverb_zone.h`, `engine/audio/src/reverb_zone.cpp`
- AABB/sphere-based reverb regions with priority
- Per-zone DSP settings (room size, damping, wet/dry mix)
- Smooth blending between zones based on listener position
- Integration with existing AudioEffectChain
- Add to audio CMakeLists.txt

### Step 6: Memory Profiler UI
- Files: `engine/perf/include/nexus/perf/memory_profiler_ui.h`, `engine/perf/src/memory_profiler_ui.cpp`
- Read from existing memory_tracker.h data
- Category breakdown (rendering, audio, physics, scene, etc.)
- Peak/current/average tracking per category
- ImGui-based visualization (bar chart, timeline)
- Add to perf CMakeLists.txt

### Step 7: GPU Profiler
- Files: `engine/perf/include/nexus/perf/gpu_profiler.h`, `engine/perf/src/gpu_profiler.cpp`
- Per-render-pass timing using GL timer queries
- Pass hierarchy: shadow → geometry → lighting → post-process
- Frame graph visualization data (pass dependencies, durations)
- Integration with existing profiler.h GPU timestamp support
- Add to perf CMakeLists.txt

### Step 8: Stress Tests
- Files: `tests/perf/test_stress.cpp`
- 10K entity creation/destruction cycle
- 100K GPU particle simulation benchmark
- Scene serialization/deserialization with 5K+ entities
- Physics broadphase with 1K+ colliders
- Render pipeline with 500+ draw calls

### Step 9: Integration Tests
- Files: `tests/integration/test_full_pipeline.cpp`
- Full engine init → scene load → simulate → render → shutdown cycle
- Asset load → material assign → render validation
- Script execute → ECS mutation → state verification
- Network connect → RPC call → state sync
- New CMakeLists.txt for integration test target

### Step 10: Doxygen + Architecture Docs
- Files: `docs/Doxyfile`, `docs/architecture.md`, `docs/getting_started.md`
- Doxyfile configured for C++ with call graphs
- Architecture guide: ECS, renderer pipeline, asset pipeline, editor
- Getting started: build instructions, first project, scripting API

### Step 11: Touch Input Abstraction
- Files: `engine/platform/include/nexus/platform/touch_input.h`, `engine/platform/src/touch_input.cpp`
- TouchEvent struct (id, position, phase: began/moved/ended/cancelled)
- Multi-touch tracking (up to 10 simultaneous touches)
- Gesture recognizer (tap, swipe, pinch, rotate)
- Mapping to existing InputAction system
- Add to platform CMakeLists.txt

### Step 12: Mobile Render Path
- Files: `engine/renderer/include/nexus/renderer/mobile_renderer.h`, `engine/renderer/src/mobile_renderer.cpp`
- GLES 3.0 compatible shader variants (no compute, limited texture formats)
- Simplified post-processing (single-pass bloom + tonemap)
- Half-resolution shadow maps
- Automatic LOD bias for mobile GPU budgets
- Add to renderer CMakeLists.txt

### Step 13: Build, Test, Commit, Push
- `cmake --build build` — clean compile
- `ctest --test-dir build` — all tests pass (865+ existing + new stress/integration)
- Commit with descriptive message
- Push to `claude/game-engine-roadmap-y0vPu`
- Final ROADMAP.md update with new score
